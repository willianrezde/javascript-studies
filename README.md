# JavaScript Studies

**Estudos, prática e evolução em JavaScript**

</div>

---

Este repositório é onde vou registrar minha evolução estudando **JavaScript**.

A ideia aqui não é apenas guardar códigos ou exercícios que funcionaram. Quero usar esse espaço para acompanhar meu aprendizado de verdade: entender a lógica por trás das coisas, registrar erros, dificuldades, pesquisas e o que eu conseguir aprender ao longo do caminho.

## Sobre os estudos

JavaScript será uma etapa importante da minha formação em desenvolvimento Front-End.

Quero aprender a linguagem entendendo os fundamentos antes de tentar partir para coisas mais complexas.

Durante os estudos, vou trabalhar conceitos como:

- lógica de programação;
- variáveis e tipos de dados;
- operadores;
- condicionais;
- estruturas de repetição;
- funções;
- arrays;
- objetos;
- métodos;
- escopo;
- manipulação do DOM;
- eventos;
- formulários;
- armazenamento de dados;
- programação assíncrona;
- consumo de APIs;
- organização do código.

Conforme eu avançar, os exercícios e projetos também vão ficando mais complexos.

## Como estou estudando

Não quero apenas decorar sintaxe.

Quero entender **por que**, **quando** e **como** cada coisa funciona.

A ideia é:

**pensar → tentar → pesquisar → testar → errar → entender → corrigir → documentar.**

Nem sempre vou saber como resolver um problema de primeira. Isso faz parte do processo.

Quero desenvolver a capacidade de olhar para um problema, dividir ele em partes, pensar em possíveis soluções e pesquisar quando não souber alguma coisa.

## Exercícios

Os exercícios serão usados para praticar os conceitos enquanto avanço no estudo da linguagem.

No começo, serão problemas mais simples para desenvolver a lógica e entender os fundamentos.

Depois, os conhecimentos serão combinados em exercícios e projetos maiores.

Quero evitar estudar cada conceito de forma isolada e esquecer o que veio antes. Por isso, sempre que possível, exercícios novos também vão exigir conhecimentos que já foram estudados anteriormente.

## Projetos

Além dos exercícios, vou desenvolver projetos para colocar os conhecimentos em prática.

A intenção é sair aos poucos de problemas pequenos e chegar em aplicações que exijam mais planejamento, organização e resolução de problemas.

Os projetos também serão uma oportunidade para perceber onde ainda tenho dificuldade e quais conceitos preciso revisar.

## Documentação

Sempre que possível, vou documentar os exercícios e projetos.

Quero registrar:

- o que o problema pedia;
- como interpretei o problema;
- como pensei na solução;
- o que precisei pesquisar;
- quais erros encontrei;
- como resolvi os problemas;
- o que aprendi;
- o que ainda não consigo explicar completamente.

Não quero esconder os erros.

Se uma solução deu errado, se precisei tentar várias vezes ou se não entendi alguma coisa de primeira, isso também faz parte do aprendizado e merece ser registrado.

## Objetivo

Meu objetivo com esse repositório é construir uma base sólida em **JavaScript e lógica de programação**.

Não quero apenas conseguir escrever um código que funciona.

Quero conseguir entender o problema, pensar em uma solução, explicar meu raciocínio, pesquisar quando necessário e entender o que meu código está realmente fazendo.

Este repositório vai ser o registro desse processo.

**Ainda estou aprendendo. E a ideia é que esse repositório mostre justamente essa evolução.**
